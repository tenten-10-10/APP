# プライバシーポリシー（プロットネームAI / PlotName AI）

最終更新日: 2026-07-02
（公開URLは配布時に設定し、App Store Connect の「プライバシーポリシーURL」に登録してください）

プロットネームAI（以下「本アプリ」）は、漫画のプロット・ページ割り・ネームをAIで
生成する創作支援アプリです。本アプリは、利用者のプライバシーを尊重し、収集する情報を
目的に必要な最小限に保つよう設計されています。

## 1. 収集・保存する情報

### 1.1 アカウント情報

- Sign in with Apple によるサインイン時に、Apple から提供されるユーザー識別子と、
  利用者が共有を選択した場合のメールアドレス（Apple の非公開リレーアドレスを含む）を
  取得します。氏名・パスワードは取得しません。
- アカウント情報は、作品データの同期・購入状態の照合・お問い合わせ対応にのみ使用します。

### 1.2 作品データ

- 利用者が入力・生成したアイデア、プロット、13フェイズ構成、ページ割り、セリフ、
  ネーム（コマ枠・配置・ラフ画像）、プロジェクト設定を、端末内に保存します。
- 同期を有効にした場合は、運営者が管理するサーバー（クラウドデータベース）にも
  保存されます。作品データを本人の同意なく公開したり、第三者へ販売することはありません。

### 1.3 使用量・課金情報

- 生成回数・AIクレジット残高・サブスクリプションの購読状態など、プラン制限の適用と
  不正利用防止に必要な使用量情報を記録します。
- 購入処理は Apple（App Store）が行います。クレジットカード番号などの決済情報を
  本アプリおよび運営者が取得することはありません。

### 1.4 クラッシュ・分析情報

- アプリの品質改善のため、クラッシュログおよび画面遷移などの利用状況を、個人を特定
  しない形で収集することがあります。これらは機能改善以外の目的には使用しません。

## 2. AI処理におけるデータの取り扱い

- 本アプリのAI機能を使用すると、利用者が入力したアイデア・プロット・生成指示などが、
  生成処理のために運営者のサーバーを経由して外部のAIプロバイダ（OpenAI 等）へ
  送信されます。
- 送信は各プロバイダの API を通じて行われ、**利用者の入力・生成結果をAIモデルの学習に
  使用させない設定・契約条件で利用します**。運営者自身も、利用者の作品を機械学習の
  学習データとして使用しません。
- Mock（オフライン）モードでは、AIプロバイダへの送信は一切行われません。
- 実在の漫画作品名・作家名を指定した模倣生成のリクエストは、安全機能により拒否されます。

## 3. 広告

- 本アプリは、無料プランで生成回数を追加するための**リワード広告（利用者が任意に視聴を
  選ぶ動画広告）のみ**を採用しています。バナー広告・全画面広告は原則表示しません。
- 広告のトラッキングのために、iOS の App Tracking Transparency（ATT）の許可を
  求めることがあります。**許可しなくても本アプリの全機能を利用できます**（その場合、
  広告はパーソナライズされないコンテキスト広告になります）。
- 広告SDKが取得する情報の取り扱いは、各広告事業者のプライバシーポリシーに従います。

## 4. データの削除

- **アカウント削除**: アプリ内の「設定 > アカウント > アカウントを削除」から、
  アカウントとサーバー上の作品データ・使用量情報を削除できます（反映まで時間が
  かかる場合があります）。
- **作品の削除**: プロジェクトを削除すると、端末および同期先サーバーから削除されます。
- アプリを削除すると端末内のデータは失われます。必要な作品は事前に PDF / PNG /
  project.json で書き出してください。
- 削除のご依頼・ご不明点は下記お問い合わせ先でも承ります。

## 5. 第三者提供

- 法令に基づく場合を除き、個人情報を第三者に提供しません。AIプロバイダ・広告事業者・
  クラウド基盤への処理委託は、本ポリシーに記載の目的の範囲でのみ行います。

## 6. 未成年の利用

- 本アプリの課金機能の利用には、保護者の同意が必要な場合があります。App Store の
  ペアレンタルコントロールもあわせてご利用ください。

## 7. 改定

- 本ポリシーを改定する場合は、アプリ内またはストアページでお知らせします。重要な変更が
  ある場合は、改めて同意をお願いすることがあります。
