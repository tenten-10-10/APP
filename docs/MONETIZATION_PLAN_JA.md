# タナミル 収益化プラン（1.3.0〜）

## モデル: フリーミアム＋「タナミル チーム」サブスクリプション

- **無料**: 1人での在庫管理は全機能無制限（QR発行/スキャン/貸出/棚卸し/履歴/書き出し/自分の端末間のiCloud同期）
- **タナミル チーム（自動更新サブスク）**: プロジェクト共有（招待・共同編集）
  - 課金が必要なのは**共有を開始するオーナーのみ**。参加者は無料
  - 既存の共有（ペイウォール導入前に作成）は**そのまま動作**（新規共有の開始のみゲート）
  - Web借用受付は当面無料のまま（昭和商会が使用中のため。コード配布が浸透した後の版でチーム機能へ編入）

## 昭和商会の無料化: Appleオファーコード（正規ルート）

独自の解除コードは審査規約3.1.1（IAP以外での機能解除の禁止）に抵触するため使わない。

1. App Store Connect → アプリ → サブスクリプション → 対象商品 → **オファーコード**
2. カスタムコードを作成（例: `SHOWA2026`）: **無料・期間1年**、引き換え可能期間は最長（6ヶ月）
3. コードを社内配布 → 各自がアプリ内「コードを使う」（設定 > タナミル チーム、またはペイウォール）から引き換え
4. 年1回、翌年分コードを再発行して配布（引き換え期限が6ヶ月のため、年2回配布でも可）

## App Store Connect 側の作業（アカウント保有者のみ実行可能）

1. **契約/税金/口座**: 「有料アプリ契約」への同意＋銀行口座・納税フォーム登録（未登録なら最初に必要）
2. サブスクリプショングループ「タナミル チーム」を作成
3. 上記2商品を作成（価格・ローカライズ表示名「タナミル チーム（月額/年額）」・審査用スクショ）
4. 各商品に**導入オファー: 2週間無料**を設定
5. オファーコード発行（昭和商会用）
6. 1.3.0の審査提出時、**初回はサブスク商品をバージョンに添付して同時審査**

## アプリ実装（1.3.0で実装済み）

- `Monetization/EntitlementService.swift`: StoreKit 2。`Transaction.currentEntitlements`＋`Transaction.updates`で `hasTeamFeatures` を導出（ローカルキャッシュによりオフラインでも有効判定）
- `Monetization/PaywallView.swift`: 価格表示（StoreKit実価格）・トライアル表示・購入・**復元**・**コードを使う**（iOS16+はofferCodeRedemption、iOS15はSKPaymentQueueフォールバック）・利用規約（Apple標準EULA）/プライバシーポリシーへのリンク・自動更新の説明（すべて審査必須要件）
- ゲート: `ProjectShareSection` — `.notShared`かつ未購読のときのみペイウォールへ誘導。オーナー（既存共有）・参加者は非ゲート
- 設定に「タナミル チーム」行（状態表示＋ペイウォール入口）
