# App Store 用 文言（草案）

実際の登録時に文字数制限（タイトル30字 / サブタイトル30字 / キーワード100字 /
プロモ170字）を確認してください。

## アプリ名（タイトル / 30字以内）

```
タナミル - QRを発行して在庫を簡単に管理
```

> ホーム画面のアイコン名（CFBundleDisplayName）は短く「タナミル」。App Store タイトル
> は上記の名前＋説明併記。内部のプロジェクト/ターゲット名は引き続き `ProjectStock`。

## キャッチコピー候補（見出し・プロモ用）

```
1. 棚の中が、見える。                         ← ブランド名（棚＝タナ／見る＝ミル）直結【イチオシ】
2. 貼って、スキャン。在庫管理はこれだけ。
3. QRを発行して、サンプルも在庫もロットも簡単管理。
4. ピッと読むだけ、在庫の「今」がわかる。
5. 印刷して貼るだけ。スマホひとつで棚卸し。
6. サンプル・在庫・ロットを、QRでまるっと管理。
```

## プロモーションテキスト（170字以内）

```
サンプル・部品・備品にQRラベルを発行して貼り、iPhoneでスキャンするだけ。入庫・出庫・
移動・棚卸し・ロット管理を記録し、在庫はイベント台帳から正確に再計算。プロジェクト単位で
```

## 説明文（Description）

```
タナミル は、サンプル・部品・製品・備品・試作品・消耗品を「プロジェクト単位」で管理できる、
iPhone 向けの QR 在庫管理アプリです。外部サーバーや会員登録は不要。データはお使いの
iCloud に保存され、オフラインでも快適に使えます。

■ QRラベルで現場をそのまま記録
・対象物や箱・棚にQRラベルを貼り、iPhoneでスキャンして入庫/出庫/消費/返却/移動/棚卸し
・QRには商品名や数量を埋め込まず、短い不透明IDだけを格納（情報漏えいに配慮）
・空のQRを先に印刷して貼り、後から製品・個体・保管場所へ割り当てることも可能

■ 追跡できる在庫台帳
・在庫数を直接書き換えるのではなく「イベント」を積み上げて管理
・誤入力は履歴を消さずに訂正（逆仕訳）。数量はいつでも台帳から再計算
・「最後にどこで何が起きたか」を製品ごとに表示、探し物に強い

■ 高品質なQRラベル書き出し
・8/16/28mm のプリセット + カスタムサイズ
・透過PNG / ベクターPDF / ベクターEPS
・読取信頼性（QR Fit）スコアと、印刷校正シートで実機確認

■ 貸出と返却期限のお知らせ
・個体（シリアル）を「誰が・いつから・いつまで」借りているかを記録
・返却期限を過ぎると端末内のローカル通知でお知らせ（サーバー送信なし）
・「貸出中」一覧で期限超過をひと目で把握、その場で返却

■ ロット（バッチ）と有効期限
・ロットごとに数量・有効期限・QRラベルを管理
・期限切れ／期限間近をバッジ表示で見逃さない

■ コンテナQRで一括移動
・箱や棚のQRを読むだけで、その中身をまとめて別の場所へ移動

■ iCloudでチーム共有
・プロジェクト単位で共有、閲覧のみ/編集可の権限に対応
・複数端末・複数Apple IDで同期、オフライン編集も復帰後に統合

広告SDK・解析SDK・第三者ライブラリは使用していません。あなたの在庫情報は、
あなたの端末とiCloudの中だけにあります。
```

## App Privacy（Nutrition Label）回答の指針

- データ収集: **なし**（開発者はデータを収集しない。iCloud はユーザー自身のアカウント）
- トラッキング: **なし**
- サードパーティ広告: **なし**
- 貸出先（借り手名）等はユーザーが入力するコンテンツで、ユーザーの iCloud にのみ保存。
  開発者は取得・閲覧できないため「収集」には該当しません。
- 通知はローカル通知のみ（リモートプッシュ・解析目的の送信なし）。
