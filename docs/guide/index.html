HOW IT WORKS

しくみは、3つだけ。

バーコードの登録も、商品マスタの準備もいりません。先にQRを刷って、貼って、あとから「これは○○」と教える——現場のスピードに合わせた順番です。

STEP A

空のQRをまとめて印刷

中身が決まっていなくてOK。A4に敷き詰めて一気に発行します。

STEP B

現物・棚・箱に貼る

届いたサンプル、置き場所、通い箱。貼る場所は自由です。

STEP C

スキャンして登録

かざして「これは○○」と名前を付けるだけ。以後はかざせば入出庫。

GETTING STARTED

サンプル管理を始める

初回起動時に操作者名（あなたの名前）を入れておくと、履歴に「誰がやったか」が残ります。ここからは5分で終わります。

  2. 右上の ＋ をタップ
  3. 名前を入れて 作成

2

空のQRをまとめて発行 → 印刷

プロジェクトを開き、メニュー（…）から 「空のQRをまとめて発行」。枚数を決めて 「作成して書き出す」 を押すと、A4のラベルシート（PDF）ができます。そのままAirPrintやコンビニ印刷でOK。

  1. A4いっぱいに敷き詰める で一気に量産
  2. 間隔0mm＋枠線が初期設定。カッターで直線に切るだけで切り離せます
  3. 発行したQRは一意に予約済み。同じシートの刷り直しもボタン一つ
普通のコピー用紙＋透明テープでも十分使えます。ラベルシールを使う場合はサイズと間隔を用紙に合わせて調整。

3

現物・棚・箱に貼る

印刷したQRを、届いたサンプルそのものや、置き場所の棚・保管箱に貼ります。この時点ではQRはまだ「空」——どれに何を貼ったか覚えておく必要はありません。次のスキャンで教えてあげるからです。

モノに貼るか、場所に貼るかは自由。「モノに1枚・置き場所に1枚」が、あとで移動管理まで効く鉄板パターンです。
4

スキャンして「これは○○」と登録

下のタブの スキャン でQRにかざすと、空のQRなら割当画面が開きます。「このQRに品物を登録」 をタップして名前を入れるだけ。

  1. かざす → このQRに品物を登録
  2. 名前（例:「試作基板 Rev.B」）を入力 → 作成して割り当て
  3. そのまま 続けて次のQRをスキャン で連続登録
登録済みの製品・場所への割り当てもここから。棚に貼ったQRは「保管場所」として登録しておくと移動管理に使えます。

5

ふだんは、かざして「持ち出し・返却」

登録が済んだQRにかざすと、そのサンプルの「今」——名前・置き場所・状態——が即座に開きます。あとは日々こう回すだけです。

  1. 確認：かざす → どこにある・誰が持っているかが一目で分かる
  2. 持ち出し：客先や展示会へ持って行くときは 貸出（誰が・いつまで。期限を過ぎたら通知）
  3. 戻ったら：かざして 返却。置き場所が変わったら 場所を移動

操作はすべて履歴（活動タブ）に「いつ・誰が・何を」で自動記録。「あのサンプル、いまどこ？」がなくなります。

配布して減っていくサンプル（試供品・ノベルティなど）は 入庫／出庫 で数を管理。名前から探したいときはホームの検索が最速です。

TEAM

チームで、同じ在庫を見る。

プロジェクトは招待リンクで共有できます。プロジェクトの「共有」タブから 「招待リンクを送る」 — アプリの入手先と参加リンクがひとつのメッセージになって送られるので、相手はリンクを開いて参加するだけ。入出庫・貸出・棚卸しが全員にリアルタイムで反映され、履歴には「誰がやったか」も残ります。メンバーごとに「編集可／閲覧のみ」を選べます。

AND MORE

サンプル管理の先に。

サンプル管理とまったく同じ「貼って、かざす」の操作のまま、在庫・ロット・棚卸しまで広がります。どれも追加設定は数タップ。

在庫管理・要補充アラート

製品に「最低在庫」を設定しておくと、下回った瞬間に「要補充」表示。発注のタイミングを逃しません。

ロット・使用期限の管理

同じ製品でも入荷ロットごとにQRを分けて、使用期限を登録。期限切れ・期限間近をホームで一覧できます。

棚卸し

連続スキャンで実数をどんどん数えて、期待との差分をワンタップで確定。差分ゼロなら「完了」を押すだけです。

履歴・書き出し

すべての入出庫が追記型の台帳に記録され、CSVで書き出せます。監査にも棚卸しにも。

FAQ

よくある質問

QRコードに商品情報は入っていますか？

入っていません。QRには短い識別子だけが入っており、名前や数量などのデータはお使いのiCloudにのみ保存されます。外部に漏れる心配はありません。

アカウント登録は必要ですか？

不要です。インストールしてすぐ使えます。データはiPhoneとあなたのiCloudに保存されます。

印刷はどんなプリンタでも大丈夫？

A4が刷れれば大丈夫です。家庭用インクジェット・コンビニのマルチコピー機でも読み取りテスト済みです。かすれた場合はQRサイズを大きめに調整してください。

オフラインでも使えますか？

使えます。電波のない倉庫でもスキャン・記録でき、オンラインに戻ったときに自動で同期されます。
