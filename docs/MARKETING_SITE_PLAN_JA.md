# tanamiru.l0l0.app マーケティングサイト計画

## 目的
- 第一: App Store誘導（インストール）／第二: /guide/への遷移、チームプラン認知
- 計測: Vercel Analytics（ダッシュボードON、コード不要）

## ターゲット・訴求軸
フリーランス・中小企業の現場（製造/建築/イベント/クリニック/小売）。
1. 「QRを貼って、かざすだけ。」台帳・Excel・マスタ登録不要
2. 先に貼れる（空QR→後から登録）＝決定的差別化
3. アカウント不要・データは自分のiCloudのみ・オフラインOK
4. A4普通紙で導入コストほぼゼロ

## 構成（1ページLP・ルート/index.html）
1. ヒーロー（キャッチ＋App Store CTA＋/guide/導線＋QRアニメ）
2. 課題共感3カード（どこ行った？/棚卸し憂鬱/Excel続かない）
3. しくみ3ステップ（貼る→かざす→そろう）
4. 機能グリッド6（サンプル/在庫・要補充/ロット期限/貸出/棚卸し/履歴CSV）
5. チームで使う（招待リンク・参加無料・権限。価格は1.3通過後に追加）
6. 安心材料（プライバシー/オフライン/QRに中身なし）
7. /guide/への大導線＋FAQ
8. 最終CTA＋フッター（© 2026 tanamiru）

## デザイン
ガイドの資産（qrSVG/iPhoneモック/オリーブ×ペーパー/リビール/ヘッダー）を共通化。
ヒーローは「貼る→スキャン→リストに現れる」3拍ループ。実績カウントアップは使わない。
外部依存ゼロの自己完結HTML。
